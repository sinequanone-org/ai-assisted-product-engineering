# Contributing

This repository uses the Apache License, Version 2.0. See [LICENSE](LICENSE).

A contribution is accepted under that same license. Do not send a contribution
under a different license.

## Before you open a change

1. Keep the change inside the request.
2. Do not add secrets, credentials, private keys, or local machine paths.
3. Do not add names of unpublished projects, repositories, papers, or people.
4. Use the templates in `templates/` for project evidence. Do not commit filled
   project records to this repository.
5. Run `python3 scripts/check-public-ready.py`.

## What a change must show

State which file you changed and why. A behavior claim needs the evidence named
in [STANDARD.md](STANDARD.md). A wording change needs a check that links and
terms still match the standard.

This repository does not grant permission to publish, deploy, or change
repository visibility.
